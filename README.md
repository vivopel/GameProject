2. System Inputu

- Podłączenie Unity Input System do wszystkich akcji postaci.

- Mapowanie inputów na ruch, kucanie oraz parowanie.

3. Animacje 2D

- Stworzenie szablonowych animacji 2D (chodzenie, kucanie, parowanie).

- Połączenie animacji z logiką postaci za pomocą Animatora.

4. Mechanika parowania

Parowanie wymagające precyzyjnego zgrania czasowego z atakiem przeciwnika.

Udane parowanie powoduje ogłuszenie (stun) przeciwnika.

5. Walka turowa

Zaimplementowanie pełnej sceny walki turowej od strony wizualnej:

- Animacje kamery,

- Layout sceny walki.

- Przyciski Ataku, Leczenia oraz Ucieczki

6. Quick Time Event
   
Pojawia się podczas ataku przez gracza albo podczas obrony przed atakiem przeciwnika

- Należy nacisnąć odpowiedni przycisk (Z, X lub C) wyświetlony na ekranie, w odpowiednim czasie
  
- Każdy trafiony przycisk podaczas ataku zwiększa obrażenia zadane przeciwnikowi, trafienie wszystkich przycisków podwaja zadane obrażania
  
- Każdy nie trafiony przycisk podaczas obrobny przed atakiem przeciwnika zwiększa zadawne obrażenia graczowi
